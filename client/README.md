# One2many Safety

Deliver UI layout specs to One2Many, a safety and emergency response application which applies various methods like decreased latency alert, background timer and red mode to address, alleviate and curb the scourge of gender based violence in South Africa.

It has cr 4 core views: 2FA Authentication, Safety Ping Timer, Red Mode Vault, and Support Directory

This project was built with [Lovable](https://lovable.dev).
